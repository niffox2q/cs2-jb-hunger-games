## Описание

Добавляет игровой режим «Голодные игры» в Jailbreak.  
Начальник тюрьмы может запустить режим, выбрать оружие для заключённых, после чего все террористы получают одинаковый набор оружия и включается режим «все против всех».

При старте режима активируется соответствующая серверная настройка, а по завершению раунда или при выдаче Last Request режим автоматически отключается и состояние сервера возвращается в стандартное.
